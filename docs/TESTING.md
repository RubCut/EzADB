# Тестирование

## Автоматические тесты

```bash
./gradlew :core:test
```

Покрываются:
- POSIX shell-quoting и сборка команд;
- парсеры `getprop`, `pm list packages`, `settings`, `dumpsys battery`, `df`, `wm`, `ip`;
- нормализация путей и имена файлов;
- каталог настроек и валидация типов;
- оценка риска команд;
- история терминала;
- фильтрация/сортировка приложений, файлов, настроек;
- форматтеры.

## Ручная проверка на устройстве

Минимальный сценарий:

1. Включить демо-режим, пройти все вкладки, открыть терминал, файлы, настройки.
2. Выключить демо-режим, подключиться по USB OTG.
3. Подтвердить RSA-ключ на целевом устройстве.
4. Обзор: модель, батарея, хранилище, аптайм обновляются.
5. Терминал: `getprop ro.product.model`, `ls /sdcard`, `dumpsys battery`.
6. Приложения: поиск, фильтр, запуск, отключение/включение несистемного приложения.
7. Файлы: открыть `/sdcard`, создать папку, загрузить текстовый файл, отредактировать, скачать, удалить.
8. Настройки: изменить `system/screen_off_timeout`, проверить значение, вернуть обратно.
9. Переключатели: автоповорот, тёмная тема, анимации; убедиться, что состояние читается после обновления.
10. Wi-Fi: включить беспроводную отладку, выполнить сопряжение, подключиться к порту подключения.
11. Отключить USB-кабель — приложение должно показать отсутствие подключения.

## Проверка безопасности

- Убедиться, что `adbkey.pem` не попадает в backup (`allowBackup=false`).
- Проверить диалог подтверждения для `rm -rf /sdcard/test`, `pm uninstall`, `reboot bootloader`.
- Убедиться, что демо-режим не открывает сетевых соединений.
