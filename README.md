# EzADB

**EzADB** — Android-приложение в Material Design 3 для управления другими Android-устройствами по ADB прямо с телефона или планшета. Работает через **USB OTG** и **Wi-Fi ADB**, включая беспроводное сопряжение Android 11+.

> Один Android управляет другим. Компьютер не нужен. Root на управляющем устройстве не требуется.

## Возможности

- **Подключение**
  - USB OTG с запросом системного разрешения и автоопределением ADB-интерфейса.
  - Wi-Fi по IP и порту, список недавних устройств.
  - mDNS-обнаружение `_adb-tls-connect._tcp` и `_adb-tls-pairing._tcp`.
  - Сопряжение по 6-значному коду (Android 11+).
- **Обзор устройства**
  - Модель, Android/SDK, сборка, патч безопасности, серийный номер, ABI.
  - Батарея, хранилище, аптайм, IP-адреса, размер экрана и плотность.
  - Быстрые действия: скриншот, Wi-Fi ADB, пробуждение, перезагрузка (система/recovery/bootloader).
- **Быстрые переключатели**
  - Wi-Fi, Bluetooth, режим полёта, мобильные данные, геолокация.
  - Автоповорот, «не спать», тёмная тема, анимации, экран.
  - Показ касаний, координаты касаний, виброотклик, автояркость.
- **Терминал**
  - Интерактивная PTY-оболочка (`shell_v2`) с fallback на raw shell.
  - История команд, быстрые команды, Ctrl+C, очистка, копирование вывода.
  - Предупреждение для распознанных опасных команд.
- **Приложения**
  - Список пользовательских/системных/отключённых приложений, поиск и сортировка.
  - Запуск, включение/отключение, принудительная остановка, очистка данных, удаление.
  - Установка APK с устройства, извлечение `base.apk`, переход в настройки приложения.
- **Файлы**
  - Просмотр папок через ADB sync, поиск и сортировка.
  - Загрузка и скачивание файлов через системный файловый пикер (SAF).
  - Создание папок, переименование, удаление, `chmod`, свойства.
  - Встроенный редактор текстовых файлов.
- **Настройки устройства**
  - Редактор `global` / `secure` / `system` с каталогом известных ключей.
  - Типизация, пресеты, валидация, пометки риска, пользовательские ключи.
- **Настройки приложения**
  - Светлая/тёмная/системная тема, Material You, акцентные цвета.
  - Размер шрифта терминала, подтверждение опасных действий, удержание экрана.
  - **Демо-режим** для знакомства с интерфейсом без реального устройства.

## Сборка

Требования:

- JDK 21
- Android SDK 36 / Build Tools 36
- Android Studio с поддержкой AGP 8.13 (или новее)
- Gradle 9.1 (используется wrapper)

```bash
./gradlew :core:test          # unit-тесты ядра
./gradlew :app:assembleDebug  # сборка APK
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions (`.github/workflows/android.yml`) автоматически запускает тесты ядра, собирает debug APK и загружает его как артефакт.

## Быстрый старт

1. На **целевом** устройстве включите «Для разработчиков» → «Отладка по USB».
2. Подключите целевое устройство к телефону с EzADB:
   - **USB:** кабель OTG, разрешите доступ к USB и подтвердите RSA-ключ на целевом устройстве.
   - **Wi-Fi:** включите «Беспроводная отладка», выполните сопряжение по коду, затем подключитесь к порту подключения.
3. Откройте EzADB → кнопка подключения → выберите USB/Wi-Fi/сопряжение.
4. Пользуйтесь обзором, терминалом, приложениями, файлами и настройками.

Без реального устройства включите **Настройки → Приложение → Демо-режим**.

## Безопасность

- ADB даёт широкий доступ к целевому устройству. Используйте только свои устройства или устройства с явного разрешения владельца.
- Приватный ключ ADB хранится в приватном каталоге приложения; `allowBackup=false`.
- Терминал выполняет произвольные команды на целевом устройстве. Опасные шаблоны требуют подтверждения.
- Демо-режим полностью изолирован и не отправляет команды на реальные устройства.

Подробнее: [docs/SECURITY.md](docs/SECURITY.md).

## Ограничения

- Беспроводное сопряжение зависит от реализации ADB на целевом устройстве и может работать нестабильно на некоторых прошивках.
- Часть переключателей (`svc`, `cmd`, broadcast) может требовать root или отличаться на OEM-прошивках.
- Файловые операции ограничены правами пользователя `shell`; системные разделы могут быть недоступны для записи.
- Установка пока поддерживает одиночный APK; split APK (APKS/APKM) не устанавливается.
- Нет зеркалирования экрана (scrcpy) и постоянного фонового сервиса.
